# Dein erstes Repo — Onboarding-Sandbox

Willkommen! Wenn du das hier in VS Code liest, hast du gerade dein erstes Repo heruntergeladen, ausgepackt und geöffnet. 🎉 Genau das war die Aufgabe.

## Was ist das hier?

Eine kleine Spielwiese zum Warmwerden — **noch kein Kursinhalt**. Du übst zwei Dinge:
1. Ein Repo herunterladen und als Ordner öffnen (hast du gerade geschafft).
2. Mit dem Agenten über die Dateien in deinem Ordner sprechen.

## So ist das Repo aufgebaut

So sieht ein typischer Kurs-Ordner aus. Hier ist nur der **Kontext** gefüllt, der Rest zeigt die Struktur:

- **`context/`** — Hintergrundwissen, das der Agent kennen soll. *(gefüllt)*
  - `company.md` — was die Firma macht
  - `strategy.md` — ihre Strategie
- **`input/`** — Rohmaterial, mit dem in einer Woche gearbeitet wird. *(leer)*
- **`output/`** — wo der Agent Ergebnisse baut. *(leer)*
- **`scripts/`** — Schritt-für-Schritt-Anleitungen, denen der Agent folgt. *(leer)*
- **`CLAUDE.md`** — die Datei, die der Agent beim Öffnen des Ordners immer zuerst liest.

## Probier es aus

Öffne den Copilot-Chat (Modus **Agent**) und stell ein paar Fragen zu den Kontextdateien, z.B.:

- „Fasse zusammen, was NeoEmployee macht und wie sie Geld verdienen."
- „Was ist die größte strategische Spannung in dieser Firma?"
- „Wenn du NeoEmployee wärst: welche Kunden würdest du als Nächstes suchen — und warum?"
- „Erkläre den Zusammenhang zwischen dem Time-&-Material-Modell und dem Produkt-Traum."

Es gibt kein Richtig oder Falsch. Ziel ist, ein Gefühl dafür zu bekommen, wie der Agent die Dateien in deinem Ordner liest und mit dir mitdenkt.

Viel Spaß — bis zum Kurs!
